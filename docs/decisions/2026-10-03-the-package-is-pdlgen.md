# The package and the command are named pdlgen

Status: Decided.

The maintainer decided on 2026-10-03 that the Go module, the command and the
repository directory are named `pdlgen`, in place of `cdproto-gen`. The
repository on GitHub is `chromedp/pdlgen`, and it is the home of the project from
now on. The old name `github.com/chromedp/cdproto-gen` redirects to it.

## What changed

- The module path in `go.mod` is `github.com/chromedp/pdlgen`, and every import
  uses it.
- The command is `pdlgen`. Install it with
  `go install github.com/chromedp/pdlgen@latest`.
- The default cache directory is `pdlgen` in the user cache directory. The old
  directory, `cdproto-gen`, is not read. Move it to keep the cached protocol
  files.
- The header of every generated file now reads "Code generated by pdlgen. DO NOT
  EDIT." The change is a comment, so the first release after it has no API
  change.
- The documents, the workflows and the update script use the new name.

## Older decisions

The decisions of 2026-10-03 and before use the old name where they say
`cdproto-gen`. They were renamed in place, because the name is the name of the
same project. The package `cdproto` that the project generates keeps its name.
